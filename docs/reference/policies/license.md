# مجوز {#license}

uv تحت یکی از مجوزهای زیر منتشر می‌شود:

- Apache License, Version 2.0

  [LICENSE-APACHE](https://github.com/astral-sh/uv/blob/main/LICENSE-APACHE) یا
  <https://www.apache.org/licenses/LICENSE-2.0>

- MIT License

  [LICENSE-MIT](https://github.com/astral-sh/uv/blob/main/LICENSE-MIT) یا
  <https://opensource.org/licenses/MIT>

به انتخاب شما.

مگر اینکه صراحتاً خلاف آن را اعلام کنید، هر مشارکتی که عمداً برای گنجاندن در uv توسط شما ارسال شود، آن‌طور که در مجوز Apache-2.0 تعریف شده است، تحت هر دو مجوز بالا و بدون هیچ شرط یا ضابطهٔ اضافی مجوز داده می‌شود.
